# Simple Calculator using Python
A professional calculator built with Python and tkinter.

This project implements a responsive desktop calculator UI with:
- a modern dark-themed design
- a clear numeric entry display
- buttons for digits, decimal point, basic arithmetic (+, -, *, /)
- extra operations: clear (C), backspace (⌫), percentage (%), and integer or floor division (//)
- responsive grid layout so the calculator resizes cleanly with the window

The code demonstrates:
- tkinter GUI creation
- custom button styling
- clean layout using grid
- simple calculator logic with input handling and expression evaluation
